1. Game Overview and Pillars
	Play as Pip, a little animal with many tricks up his sleeve. Befriend, defeat, and interact with the many beasts found in Dreamland to survive. Survive as long as you can throughout Dreamland and discover the mystery of the Anthurium, a mysterious ancient reality-warping plant deity.

	The player's goal is to survive until the Anthurium's final bloom; an event that is built up to throughout a game round. A round is typically around five minutes, but can be slowed down or accelerated through different methods. 

The player is part of the ecosystem
	All entities (including the player) follow the same built in rules; all entities can use items and abilities, suffer from hunger, have prey/predators, etc.
The Anthurium is the centerpiece of the game
	All special events during the game are set in motion through the plant using some mechanism.

2. Core Gameplay Loop
	The player is spawned in an already populated game board, with the Anthurium plant at the center.
